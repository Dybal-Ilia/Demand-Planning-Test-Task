# Demand Forecasting Pipeline

Производственный пайплайн автоматизированного прогнозирования спроса и поставок в ритейле. Решение построено в соответствии с прицнипами ООП и включает в себя полный цикл: предобработка сырых данных -> генерация прогноза -> рассчёт метрикю

## Особенности проекта
- Восстановлени спроса: математическая реконструкция реального спроса в периоды дефицита на полках.
- Коррекция UOM: Автоматическое детектирование и исправление аномальных скачков единиц измерения (на базе логарифмического масштабирования).
- Маршрутизация прогнозов: Динамический маппинг моделей в зависимости от ABC класса товара.
- OOF-валидация: Встроенный модуль для проверки качества моделей на исторических данных без заглядывания в будущее.

## Структура проекта
Проект упакован в соответствии с питоновским src лейаутом.

- **src/app/processors**: Классы для очистки и трансформации данных + класс-пайплайн
- **src/app/predictors**: ML/статистические/математические модели
- **src/app/orchestration**: Класс реджистри моделей и оркестратор
- **src/app/validation**: модуль OOF валидации
- **data**: исходные данные
- **notebooks**: юпитер ноутбуки для экспериментов
- **tests:**: юнит-тесты (pytest)
- **main.py**: точка входа - запуск пайплайна и валидация
- **pyproject.toml**: конфигурационный файл проекта и зависимостей
- **REPORT.md**: Отчёт о проделанной работе

## Установка и запуск
Проект использует современный менеджер пакетов **uv** (но полностью совместим с `pip`).

1. Клонирование репозитория
```bash
git clone <project-url> .
```
2. Установка зависимостей
Через **uv** (рекомендуется)
```bash
uv sync
```
Через **pip**
```
python -m venv .venv
source .venv/bin/activate (или .venv/Scripts/activate для винды)
pip install -e .
```
3. Запуск
Скрипт **main.py** разделён на две фазы: оценка качества и прогнозирование.

Через **uv**:
```bash
uv run main.py
```

Через **Python**:
```bash
python main.py
```
Результат работы сохранится в файл **submit.csv** в корне проекта.
